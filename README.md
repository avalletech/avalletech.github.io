## ⭐ Featured: [Homelab](https://github.com/avalletech/homelab)

A Proxmox VE lab on a Dell OptiPlex running the services a small IT department would: **Pi-hole** for DNS, **Nginx Proxy Manager** as a reverse proxy, a private **mkcert** certificate authority for internal HTTPS, **Uptime Kuma** monitoring with **Discord** alerts, and scheduled backups. The repo includes a network diagram and a troubleshooting log of real outages, what caused them, and how I fixed them.
